# Suíte de aplicativos OverOS

A OverOS terá aplicativos com identidade, interface, configurações e integrações próprias. Não serão apenas atalhos com nomes trocados.

| Aplicativo | Função | Estado |
|---|---|---|
| Over Browser | Navegação web | Especificado; motor e UI pendentes |
| OverStore | Catálogo e gestão de pacotes | Interface local criada; backend pendente |
| OverFiles | Arquivos e unidades | Planejado |
| OverSettings | Aparência e sistema | Preferências CLI iniciais; GUI pendente |
| OverTerminal | Terminal | Shell disponível; interface própria pendente |
| OverControl | Painel rápido e notificações | Planejado |
| OverMedia | Mídia local | Planejado |
| OverArchive | Arquivos compactados | Planejado |

## Regra do produto

Aplicativos são considerados concluídos somente quando suas funções anunciadas operam de verdade. Mockups, catálogos locais e especificações devem ser identificados como protótipos, nunca como apps finalizados.
