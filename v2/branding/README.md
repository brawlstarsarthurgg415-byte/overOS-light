# Identidade visual OverOS V2

Este diretório centraliza os primeiros recursos de marca da V2.

- `overos-logo-horizontal.svg`: símbolo + nome OverOS; "OS" em azul.
- `overos-symbol.svg`: símbolo circular isolado, para o menu Iniciar e ícones.
- `fastfetch.sh`: apresentação de identidade e informações no terminal, com o nome OverOS Lite V2.

A direção visual foi reconstruída a partir da descrição anterior: círculo branco, esfera azul e wordmark branco/azul. Não é uma cópia pixel a pixel do arquivo original enviado anteriormente; quando o arquivo original estiver disponível, ele deve substituir estes vetores sem mudar a identidade definida.

O workflow de imagem copia o script de terminal para o initramfs experimental. A aplicação de logos em GRUB, tela de boot, menu, desktop, painel web e ícones será feita à medida que esses componentes forem integrados.
